# New UI Plans

This directory is reserved for planning and working notes for the new editor-like UI.

Files:

- `01-ui-brainstorm.md`: current product direction, UX goals, architecture ideas, and open questions for the new UI.
- `02-console-ui-integration-readiness.md`: plan for making the new console UI a real backend client with a fake backend mode for demo and testing.
- `03-console-ui-post-boundary-delivery.md`: detailed follow-on plan for capability state, thread creation, diff inspection, and live-adapter contract coverage after the boundary work from plan 02.
- `07-console-ui-archived-projects-and-threads.md`: future global management surface for archived projects and archived threads.
- `06-console-ui-project-sidebar-tabs-and-panes.md`: v1 project sidebar, project-local tabs, pane layout, draft-pane lifecycle, and thread placement model for the console UI.
